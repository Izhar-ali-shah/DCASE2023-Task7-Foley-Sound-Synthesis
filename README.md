# Investigating Best-Performing Models for Foley Sound Synthesis in DCASE2023 Task 7

# Overview
This media project aims to identify the best-performing models from DCASE2023 Task 7, with an emphasis on balancing the quality of generated audio samples and the model complexity. By exploring these models, the project seeks to test their effectiveness in synthesizing industrial sounds.

# Objectives

1. Summarize the findings from the DCASE2023 Task 7 results.
2. Re-implement one of the best-performing models from the challenge.
3. Analyze the results in detail, addressing the following research questions:
-  How does the selected model's performance vary with different audio classes?
-  What factors contribute to the quality of synthesized industrial sounds?
4. Retrain and test on industrial sound datasets to evaluate its adaptability.
5. Prepare a project documentation and a final presentation.

# Datasets

The classes of audio are as follows. 

1. DogBark
2. Footstep
3. GunShot
4. Keyboard
5. MovingMotorVehicle
6. Rain
7. Sneeze/Cough

[Datasets Here](https://zenodo.org/records/8091972)
